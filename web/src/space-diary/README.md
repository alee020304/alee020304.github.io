# Space diary

Drop a drawing in this folder (`.jpg`, `.png` or `.webp`) and it shows up in
the Space diary on the My room tab, newest file name first. Name files so
they sort by date, e.g. `2026-11-kitchen.jpg`.

To write the realization under a drawing, add a text file with the same name:
`2026-11-kitchen.txt`. The first line is the title (optional, leave it blank
to skip), and the rest is the note.

Keep scans under about 500 KB; pixel-art or line drawings can be PNG.
